## Data product 1. Customer 360

| Поле | Значение |
| --- | --- |
| **Data product** | Customer 360 |
| **BIAN / Домен** | Party / Customer Profile (BIAN Operational Domain «Party») |
| **Основные данные** | global_client_id, ФИО, дата рождения, паспорт, контакты, сегмент, статусы отношений, согласия, владелец/доски (board_name), история изменений (SCD Type 2) |
| **Источник истины** | MDM (единая золотая запись) |
| **Владелец** | Data Office + CRM‑домен (совместно: Data Office—политика и качество, CRM—бизнес‑правила и актуальность) |
| **Потребители** | CRM, Core Banking, Cards, Loans, BI, Naive UI (Vue) для отображения профиля, антифрод, маркетинг |

## Data product 2. Account & Balance Hub

| Поле | Значение |
| --- | --- |
| **Data product** | Account & Balance Hub |
| **BIAN / Домен** | Account Management (BIAN Operational Domain «Account») |
| **Основные данные** | global_account_id, валюта, тип счёта, владелец (global_client_id), дата открытия/закрытия, текущий остаток, статус счёта, история остатков (point‑in‑time) |
| **Источник истины** | Core Banking (мастер по счетам и остаткам) |
| **Владелец** | Core Banking Team (операционные данные), DWH Team (витрины и качество для BI) |
| **Потребители** | Cards, Loans, Payments, BI (отчёты по остаткам), регуляторная отчётность, Naive UI для отображения баланса |

## Data product 3. Transaction & Event Timeline

| Поле | Значение |
| --- | --- |
| **Data product** | Transaction & Event Timeline |
| **BIAN / Домен** | Transaction Processing / Payments (BIAN Operational Domains «Transaction Processing», «Payments») |
| **Основные данные** | transaction_id, event_timestamp_utc, global_client_id, global_account_id, amount, currency, channel, status, kafka_event_id (для трассировки), источник системы |
| **Источник истины** | Core Banking + Kafka (событийный журнал) |
| **Владелец** | Core Banking Team + Data Platform Team (Core—мастер по транзакциям, Data Platform—событийная шина и трассировка) |
| **Потребители** | Антифрод (правила по транзакциям), риск‑менеджмент, BI (обороты, тренды), расследования, регуляторная отчётность |

## Data product 4. Product & Offer Catalog

| Поле | Значение |
| --- | --- |
| **Data product** | Product & Offer Catalog |
| **BIAN / Домен** | Product Management / Sales & Marketing (BIAN Operational Domains «Product», «Sales & Marketing») |
| **Основные данные** | product_id, название продукта, категория, линейка, тарифы, условия, статусы (активен/архив), владелец продукта, правила назначения (кому можно предлагать) |
| **Источник истины** | Product Management System / Core (справочник продуктов) |
| **Владелец** | Product Team + Core Banking Team (Product—бизнес‑правила, Core—техническая реализация и справочники) |
| **Потребители** | CRM (подбор предложений), Cards, Loans, Marketing, BI (анализ продуктового портфеля), Naive UI (отображение доступных продуктов) |
