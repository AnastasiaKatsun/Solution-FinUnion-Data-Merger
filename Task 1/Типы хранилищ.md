| Сущность | Тип хранилища | Почему именно это хранилище |
| --- | --- | --- |
| **Клиент** | **MDM** (мастер) + **OLTP** (операционные копии) | MDM хранит «золотую запись» (global_client_id, правила дедупликации, маппинг external_ids). OLTP хранит операционные данные (контакты, статусы) для быстрого доступа в Core/CRM. |
| **Счёт** | **OLTP (Core Banking)** + **DWH** | Core—мастер для операций, балансов, статусов (ACID, быстрые транзакции). DWH—для отчётности, витрин, исторических остатков и сверки. |
| **Карта** | **OLTP (Карточная система)** + **DWH** | Карточная система—мастер статусов, правил блокировки/активации (state machine). DWH—аналитика по операциям, фрод-мониторинг, SLA. |
| **Кредит / Договор кредита** | **OLTP (Кредитная система)** + **DWH** | Кредитная система—мастер по лимитам, графикам, просрочкам, скорингу (ACID). DWH—отчётность по портфелю, резервы, риск-метрики. |
| **Транзакция** | **OLTP (Core/Процессинг)** + **Data Lakehouse** + **DWH** | OLTP—для быстрых операций, сверки, антифрода (высокая частота записи). Data Lakehouse—сырые события, CDC-потоки, ML/аналитика. DWH—агрегации, отчётность, витрины. |
| **Продукт / Тариф** | **MDM / Каталог продуктов** + **DWH** | Каталог—мастер справочников (версионирование, approval workflow). DWH—витрины продуктовой линейки для BI и каналов продаж. |
| **Обращение клиента (Case)** | **OLTP (CRM)** + **Поисковый движок** + **DWH** | CRM—мастер статусов и жизненного цикла (state machine: New→Assigned→Resolved→Closed). Поисковый движок (Elasticsearch)—быстрый поиск по тексту обращений, фасетам, SLA. DWH—метрики качества обслуживания. |
| **Договор (юридический)** | **OLTP (Core/Архив)** + **Объектное хранилище** | Core/Архив—метаданные, статусы, версии, подписи. Объектное хранилище (S3)—файлы PDF/скан-копии, архивы, выгрузки. |
| **Платёж** | **OLTP (Платёжный шлюз/Core)** + **DWH** | Платёжная система—мастер маршрутизации, статусов, лимитов. DWH—сводная отчётность, сверка, контроль дублей. |
