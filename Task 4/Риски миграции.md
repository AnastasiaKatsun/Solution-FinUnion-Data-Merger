## Таблица рисков миграции (клиентские данные)

| Риск | Влияние | Вероятность | Митигация |
| --- | --- | --- | --- |
| **Дубли клиентов в MDM** | Ошибки в профиле, двойные коммуникации, неверные статусы в state machine, некорректные отчёты в BI и UI | Высокая | Правила сравнения (ФИО + дата рождения + паспорт); ручная верификация спорных случаев; SLA на долю дублей \< 0.1%; контрольные суммы и lineage в DataHub |
| **Расхождение остатков/статусов между Core и DWH** | Неверные балансы в UI (Naive UI), ошибки в отчётах, регуляторные риски | Средняя–Высокая | Контрольные суммы по дням; dbt‑тесты качества; сверка выборок (1–5% клиентов); фиксация SLA расхождений ≤ 0.01% |
| **Потеря событий в Kafka** (пропуск транзакций/изменений) | Неполная история для расследований, разрыв трассировки event_id → kafka_event_id, ошибки в state machine | Средняя | Репликация топиков (≥ 2), мониторинг lag, фолбэк на файловые выгрузки с шифрованием; неизменяемый журнал в Lakehouse |
| **Нарушение SLA витрин DWH** (данные не успели обновиться) | UI (Vue + Naive UI) показывает устаревшие данные; отчёты BI неактуальны | Средняя | Микропакеты (частые загрузки), кэширование в BI, показ даты последнего обновления в UI, circuit breaker при таймаутах |
| **Утечка** (паспорт, контакты) **при миграции** | Регуляторные штрафы, репутационные риски, нарушение ИБ | Низкая–Средняя | Маскирование на источнике; mTLS на всех потоках; RBAC и аудит доступа; шифрование файлов выгрузок; запрет прямых запросов к PII вне MDM |
| **Сбой CDC (Debezium) из Core Banking** | Остановка потока данных, рассинхронизация витрин, задержки в UI | Средняя | Резервные скрипты выгрузки; мониторинг коннекторов; фолбэк на ночные дампы; RTO ≤ 4 часа |
| **Конфликты правил переходов state machine** (разные статусы в разных системах) | Блокировка операций, неверные переходы, ошибки в UI и API | Средняя | Единый справочник статусов (dim_status) в DWH; все сервисы читают статусы только оттуда; запрет хардкода статусов в коде |
| **Проблемы интеграции UI (Naive UI) с новыми витринами** | UI не отображает данные, ошибки при загрузке, плохой UX | Низкая–Средняя | Тестовые стенды с реальными данными; поэтапное переключение (канареечный релиз); показ статуса «данные временно недоступны» при сбоях |
| **Неполнота lineage и метаданных в DataHub** | Сложно расследовать ошибки, нет понимания, откуда пришли данные | Средняя | Автофиксация lineage в dbt; тегирование data‑продуктов; назначение владельцев и SLA в DataHub |
